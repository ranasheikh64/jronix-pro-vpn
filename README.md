# Jronix Pro VPN — Official Landing Page

Luxury, high-converting, and responsive landing page for **Jronix Pro VPN**.
Built with pure vanilla HTML5, CSS3, and modern ES6+ JavaScript.

## ✨ Features
- **Deep Space & Luxury Amber Theme:** Matches the exact color palette and UI aesthetic of the Flutter app.
- **WireGuard® Showcase:** Highlights ultra-low latency, military-grade ChaCha20 encryption, and zero-log architecture.
- **Interactive Server Grid:** Features live latency test buttons for US, Germany, Singapore, UK, and Japan.
- **Real Device Mockups:** Showcases 4 real app screens in sleek phone frames.
- **Auto-Sync Release Links:** Automatically fetches the latest APK release and version tag via the GitHub API.

## 🚀 Live Preview
Open `index.html` in any modern web browser or serve with:
```bash
python3 -m http.server 8080
```
